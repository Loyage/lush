    开发环境

    环境表示项目实际所在的机器与用户。SSH 与 HTTPS 是接入方式，不是项目类型。

    通过 SSH 连接 Linux 服务器

    本机 SSH 配置

    读取本机用户 SSH config 及 Include 中的明确 Host 别名，不显示配置原文或密钥。点击服务器后自动预检；已安装则直接连接，首次安装仍需确认计划。

    正在读取本机 SSH 配置…

      手动输入服务器

      使用系统 SSH 配置中的 Host。请先在终端执行 ssh my-server，核对主机身份并配置密钥 / ssh-agent。这里不输入或保存密码、私钥或模型凭证。

      确认远端计划

      
          
        
          
        本机缺少匹配运行包时，确认后从计划中的固定 GitHub Release 下载到本机缓存，校验版本、源码指纹及哈希后才上传；下载失败不安装。仅在 SSH 用户目录安装 Lush 和私有 Bun，不使用 sudo，不更改系统 PATH、防火墙或自启服务。随后启动远端 Host，并由远端页面选择项目、启动或连接其 daemon。Git、Agent 及认证需在远端准备；连接成功不代表模型已就绪。
        
          
        
        
        
        
        
        SSH 连接记录
        
        
        点击记录自动预检；已安装则直接连接，首次安装需确认。断开隧道不停止远端开发。
        
        
          
      
          
      
          
        
          已有 HTTPS Host
          
        
          
          
          
          
          只连接你信任的 Lush Host。公网使用 HTTPS；SSH 隧道请自行建立，再填 http://127.0.0.1:端口。这里不保存密码或 SSH 密钥。
          
          
        
          
        
          登录和项目选择在远端页面完成，项目路径属于远程机器。
          
      
          
    
          

    
          
      
          SETTINGS
          桌面设置
          项目与 Agent 设置保存在对应项目中；这里说明桌面壳的固定行为。
          
      
          
        
          窗口与会话
          每个 Host 使用隔离会话，每个项目在独立窗口打开，不覆盖其他窗口的输入。
          
        
          后台所有权
          关闭窗口不会停止项目 daemon。退出桌面只回收桌面自己启动的本地 Host 与 SSH 隧道。
          
        
          安全边界
          远程页面不能调用本机 SSH、读取 SSH 配置或执行任意本机命令。
          
      
          
    
          

    
          
      
          HELP
          使用帮助
          连接失败不会自动重发 Worker 操作。修复环境后请显式重试。
          
      
          
        
          本机项目
          macOS / Linux 通常直接进入完整工作台。若本地 Host 启动失败，本管理壳仍可用于环境连接。
          
        
          Windows
          当前 Windows 客户端不启动本地 Bun、Host 或 daemon。请在「环境」中连接 Linux / macOS Host。
          
        
          SSH 主机信任
          先在终端连接一次并核对主机指纹。Lush 不关闭主机校验，也不保存密码或私钥。
          
        
          完整文档
          打开任一项目工作台后，使用侧栏「帮助文档」查看随当前版本发布的文档。
