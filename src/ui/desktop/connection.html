    手动输入服务器

    使用系统 SSH 配置中的 Host。请先在终端执行 ssh my-server，核对主机身份并配置密钥 / ssh-agent。这里不输入或保存密码、私钥或模型凭证。

    确认远端计划

    
        
      
        
      仅在 SSH 用户目录安装 Lush 和私有 Bun，不使用 sudo，不更改系统 PATH、防火墙或自启服务。随后启动远端 Host，并由远端页面选择项目、启动或连接其 daemon。Git、Agent 及认证需在远端准备；连接成功不代表模型已就绪。
      
        
      
      
      
      
        
      
      
      
      SSH 连接记录
      
      
      点击记录自动预检；已安装则直接连接，首次安装需确认。记录只保存入口元数据。断开隧道不停止远端开发；已打开的窗口会离线，重新连接不会自动重发 Worker 操作。
      
      
        
    
        
    
        
      
        本地项目
        
      
        源码启动需要本机 Bun；macOS 安装包已携带私有 Bun。打开后可选择本地项目目录。
        
      
    
        
    
        
      
        远程 Host
        
      
        
        
        
        
        只连接你信任的 Lush Host。公网使用 HTTPS；SSH 隧道请自行建立，再填 http://127.0.0.1:端口。这里不保存密码或 SSH 密钥。
        
        
      
        
      
        登录和项目选择在远端页面完成，项目路径属于远程机器。远程模式不需要本机 Bun。
        
    
        
    
        
      
        最近远程连接
        
      
        仅移除记录不会退出登录、关闭窗口或停止远端服务。
        
      
          
    
          
    
          可随时通过桌面「连接」菜单打开更多窗口。连接失败可重试；不会自动重发 Worker 操作。
