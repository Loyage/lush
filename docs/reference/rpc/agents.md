# Agent 状态

本文说明 Web「Agent 状态」页面的只读查询范围与限制。后端入口是 `src/agent/status.js`，UI 入口是 `src/ui/web/assets/render-agent-status.js`；完整字段契约见[模块地图](../../engineering/modules.md#agent-状态只读查询接缝)。

## 入口与作用域

- RPC：`agent.status {}`，不接受参数，**仅用户可调用**。
- HTTP：`GET /api/agent/status`，全局 Host 模式必须带 `/p/<project-id>` 前缀，沿用现有登录和项目身份校验，响应 `Cache-Control: no-store`。
- UI：其他分组的「Agent 状态」，直达 hash 为 `#agent-status`；进入页面立即查询，之后手动刷新，不自动轮询，不启动 Agent 或模型调用。
- 数据来自项目 daemon 的 Pi 命令及公共 / `agent` 角色环境与角色配置，不是浏览器本机，不是某个 Task 已启动 invocation 的快照。环境按下一次调用配置热读取；运行中的调用不受影响。

## 可查看的信息

| 区域 | 来源与含义 |
|---|---|
| 安装与配置 | 配置的 Pi 命令、解析后的可执行文件与实际文件地址、版本、Pi 配置目录、当前项目 Agent 后端和模型；读取失败为未知 |
| 账号 | 本地 `auth.json`、模型配置或已知凭证环境变量；只返回来源、认证类型、本地配置 / 过期 / 未知状态、服务端脱敏身份与到期时间 |
| 模型 | 已安装 Pi SDK 的本地模型元数据，按本地已配置且未过期的凭证匹配；可在页面搜索和按服务商筛选，不联网验证请求是否成功 |
| 资源 | 用户 / 项目目录、已配置包及当前角色显式选择的扩展和 Skills；包声明不等于已安装，未发现安装路径会说明，目录也不代表资源已在 Task 加载 |
| 查询反馈 | 数据时间、分区 warning、网络错误或不支持原因；刷新失败保留旧结果并明确标为非最新 |

## 余额和额度

只对当前 Agent 配置的服务商进行已接入的官方查询，不自动遍历所有保存账号发请求。

- **DeepSeek**：官方余额接口，按返回币种展示现金余额。
- **OpenRouter**：官方 Key 信息接口，展示 API Key 消费上限、剩余额度与用量；这不是账户现金余额。无上限时数值保留未知，不显示为零。
- **ChatGPT/Codex 订阅及其余未接入服务商**：明确显示无法查询及原因，不通过非官方网页接口猜测额度。
- 自定义端点 / 代理账号不会仅因服务商 ID 相同就把凭证送到官方服务。没有可安全读取的查询凭证时不查询。
- 网络、授权、超时或格式失败与真实零分开呈现；未知数值为 null，余额和额度不得互换。

## 安全与限制

查询不返回密钥、token、原始凭证配置、原始 CLI 错误或上游响应；不会执行 `!` 密钥命令，不刷新或写回 OAuth 凭证，不加载扩展代码。官方请求固定 HTTPS 地址、禁用重定向，并限制响应大小与时间。

模型 source=`local` 表示本地目录与本地凭证匹配，不等于联网验证可用。扩展提供的动态模型不加载，ambient cloud 凭证也不主动探测。Pi SDK 不兼容或无法定位时，source=`presets` 明确展示内置预设回退，不冒充实际可用模型。大目录有界截断并显示说明。

目前该页查询 Pi；如项目选择 Codex 后端，安装区域仍会说明当前后端，账号与目录不冒充 Codex CLI 的状态。修改代码后需在合入并确认项目无活动调用时重启 daemon 和 Host 才能启用新入口；查询本身不会重启服务。
