# 统计面板

Web 与桌面左栏的「统计面板」（`#statistics`）展示当前项目的累计 token、预计花费、分时柱状图及模型费用明细。实现入口为 `src/core/usage-statistics.js` 与 `src/ui/web/assets/render-statistics.js`。

## 使用

- 不设置时间时，统计当前项目保留会话中迄今为止的全部用量；不跨项目。
- **日间 · 按天**：提供最近 7 天、最近 30 天、本月、全部历史和自定义日期。默认全部历史；日历选择的起止日期均包含当天，也可只填写一端。每根柱代表一天。
- **日内 · 按小时**：默认今天全天，提供今天、昨天和日历选日；可选择开始／结束小时或一键恢复全天。结束小时不包含在范围内，24:00 表示次日零点。每根柱代表一小时。
- 日期与小时选择、图表分段统一使用界面明确标注的 **UTC** 时区，空白时段补零。两种视图分别保留本次页面会话中的筛选条件；切换视图或点击快捷范围立即查询，自定义日期／小时后点击「查询／刷新」。
- 每次最多展示 1500 个时间段；日间历史跨度超过 1500 天时，请选择较短的日期范围。鼠标移入柱子所在时段即显示跟随鼠标的数值浮层（预计 USD、token、记录数及缺价提示），低值／零值柱同样可查看；键盘聚焦也会显示，移出、失焦、Escape 或横向滚动时隐藏。浮层限制在可见图表范围内。
- 「查询／刷新」重新读取会话；日间「全部历史」清空日期筛选。统计不进入首页定时轮询。

## 数据口径与限制

数据源是当前项目 `.lush/sessions/*_lush-task-*.jsonl`，不是任务列表的最近一页。保留会话中的已归档、已删除任务也计入；已经删除的会话无法恢复。

- 每条 assistant 用量记录只算一次，不按回复中的思考、工具调用或文本片段重复累计。失败调用只要留下用量记录也计入。
- 总 token 优先取记录的 `totalTokens`，否则为输入、输出、缓存读取、缓存写入之和。Reasoning 通常包含在输出中，不重复相加。
- 金额均为调用时会话记录的 **预计 USD**，不是实际账单、不反映套餐余额，也不按最新价格重算。
- 缺少价格的记录标为未知；已知部分仍显示合计。记录明确给出的零价格与缺失价格区别处理。
- 缺少用量的 assistant 记录、损坏／过长的行、不可读文件均明确提示；正在写入的未完成末行等到下一次刷新再计入。
- 缺少时间的记录仅在没有时间筛选的总量／模型明细中计入，不进入时间柱状图。
- Pi 使用已有会话。Codex 从本功能启用后保存每个 `turn.completed` 的 token，用量包含缓存输入且不会重复相加；Codex 不提供价格时显示未知。此前未保存的 Codex 历史用量无法补齐；未显式选择且 CLI 没有报告的模型标为 `unknown`。
- 后端异步分块读取完整历史，不受任务详情 8 MiB 窗口限制；只缓存精简用量，不缓存工具正文、不修改历史文件或数据库。超出 16 Mi 字符的单行跳过并提示，不中止后续文件统计。

## 只读接口

`GET /api/usage?start=...&end=...&interval=auto` 对应用户专属 RPC `system.usage(start?,end?,interval?)`。公网模式要求登录，agent token 不可调用；参数不能指定其他项目或任意文件。

时间参数为带时区的 ISO 时间戳，`interval` 为 `auto|hour|day|month`（接口继续支持自动／月粒度，面板两种视图分别固定为 day / hour）。省略开始表示历史起点，省略结束表示查询时刻（包含该毫秒）。显式时间段采用 `[start,end)`。

响应包含：

- `project`、`currency='USD'`、`estimated=true`、`timezone='UTC'`、`generated_at`；
- `range`、解析后的 `interval`；
- `totals`：`requests`（用量记录数，不保证等于底层 HTTP 请求数）、`input`、`output`、`cache_read`、`cache_write`、`tokens`、`cost`、`unknown_cost`、`unknown_tokens`；
- `buckets`：UTC 日历时间段的 `start/end` 加同口径累计字段，首尾柱只累计查询范围内的记录；
- `models`：按 `provider/model` 分组的累计字段，按已知费用降序；
- `coverage`：文件数、不可读文件、损坏行、未完成文件、无时间记录和 Codex thread 数。文件覆盖问题是全历史扫描结果，不代表仅发生在所选时间段。

零记录返回零合计与空模型列表；若指定完整时间范围，柱状图仍补零。非法时间、起止倒置、未知粒度或过多分段返回校验错误。
