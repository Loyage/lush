## 已知限制与验证边界

父死亡 guard 只清理自己的进程组，不回滚文件副作用或保证 exactly-once；外部 Git 不受 Lush 队列锁保护。多项目核心身份隔离已实施，但 Host 总资源预算及真实宿主性能矩阵仍未完成。跨项目总待办 / 统一决策动作属于另行确认的新范围，不是本批漏交付。

工程专题保留历史全套因缺少 `@electron/asar` 的导入失败及超时记录；不能用历史测试数量声称当前全套通过。新方案须有明确语义、可重复回归、既有安全门未退化的证据和文档 / API 更新。验证使用临时项目、mock 和受控进程，不启停用户服务。
