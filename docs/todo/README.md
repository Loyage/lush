## 如何读证据

- **已复现**：在临时 fixture、mock、DOM stub 或受控子进程中观察到所述结果；括号中的层级是证据边界，不自动外推至真实浏览器或生产环境。
- **代码确认**：能追踪具体代码路径，但未必完成端到端复现；“缺少测试”不等于功能已坏。
- **待验证**：需要真实客户端、特定平台或规模量测后才能下结论。
- **S / M / L**：相对改动量估计，不是工时；架构或产品选择另行确认。各条目默认状态均为“待评审”。
