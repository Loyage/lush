# Worker Hooks 与预约发射

Hook 是用户挂在 Worker 上的受控规则：**触发节点 → 条件 → 动作**。它不是任意脚本，也不是一个新的 Worker。项目之间的模板、挂载和执行记录互不共享。

## 两个入口

- 侧栏「Hooks」（`#hooks`）：查看生命周期节点与动作能力，管理可复用的项目模板；选择父 Worker 后挂载原模板或新规则。
- Worker 详情「Hooks」：按触发节点查看实际挂载、等待条件、最近执行结果，启用、停用或移除自定义规则。Worker 图中的摘要入口跳到详情。

保存模板只保存规则，不执行动作。挂载原模板会在后台复制完整定义，包括私有运行设置；后续修改或删除模板不改变已有挂载。编辑模板时，同一位置的创建动作没有重新设置参数就保留已有私有覆盖；新增或移动创建动作须明确设置参数，不能从脱敏摘要猜出 Prompt/env。

## main 冻结时预约发射

1. 在主输入框选择 main，填写指令和引用；展开运行设置可选择 Agent、配置模式、模型、思考强度及完整覆盖。
2. main 冻结时，「创建 Worker」变为「预约发射 Worker」。点击会保存一次性 Hook，**此时不创建 Input、Worker 或 worktree，也不调用 Agent**。
3. 所有冻结解除、父 Worker 允许创建且 Git 准入通过后的首个安全创建边界，后台从**那时的父分支已提交 tip**创建独立 Worker/worktree。默认排队开始 Agent，不承诺执行槽立即空闲。
4. Ctrl/⌘+Enter 预约「仅创建」；Ctrl/⌘+Shift+Enter 预约「创建并开始」。未冻结时，原「创建 Worker」仍默认只创建待开始 Worker。

「历史输入」中也可以对当前一条暂存预约「创建并开始」或「仅创建」，并单独设置运行参数。正文、引用、父身份与草稿版本来自保存的草稿，不接受混入另一份正文。

预约保存完整授权快照，而不是执行时重新读取浏览器或默认设置。未显式覆盖时冻结挂载时的有效项目默认；测试/mock 后端没有可配置模型，不冒充真实模型验证。Pi 自主管理模式只冻结模式，外部 Pi 的模型、资源和认证仍在真正启动时由 Pi 解析。

## 自动合并也是 Hook

自动合并位于 Worker 详情的「本轮交付就绪」节点：**本轮安全返回、后代结算、消息和待决处理、工作区及提交检查 → 请求本轮合并**。它不是每次 Agent 返回就合并。

- 用户指令默认关闭；Agent 派生 child 默认开启且锁定。
- 开关跨轮次保留；「已开启」不等于「已发请求」，更不等于「已合并」。
- 已发请求仍由原有父 Worker 交付队列处理。关闭 Hook 不撤回已发请求；历史预约继续原协议。
- 就绪、已请求或结束后的不可编辑状态与原因仍会显示，不会用另一个 Hook 绕过门禁。

## 可用节点与动作

| 节点类别 | 例子 |
|---|---|
| Agent | 开始调用、正常返回、失败、主动暂停、抢占结束 |
| Worker | 本轮交付就绪、冻结／全部解冻、父可创建安全点、等待用户／恢复、验收、取消 |
| 交付 | 已集成、挂起、受阻 |

主动暂停与抢占不是失败；「等待用户」对应待决问题，不是每条普通通知。页面只是读取这些事实，不靠轮询触发 Hook。

每条规则最多四个有序动作，并可限制触发时的 Worker 状态和集成状态：

- **发送通知**：创建信息通知，不调用 Agent；可一次性或持续。
- **发送消息**：只发送给当前 Worker 或直接父子；可能唤醒 Agent，仅允许一次性，防止返回—消息—付费调用循环。
- **创建 Worker**：仅父可创建安全点、一次性，可选择开始 Agent 或仅创建。
- **请求合并**：仅本轮交付就绪，复用既有权限、冻结与交付队列。

可能调用 Agent 的规则与按钮带紫色标记和费用说明。没有 Shell、JavaScript、任意 RPC、跨项目或跨任意 Worker 的动作。

## 等待、失败与取消

等待中的挂载可停用或移除。预约草稿被占用时不能编辑、删除或重复发射；等待／明确失败状态下停用可释放草稿，重新启用时后台重新核验版本与占用。父 Worker 已取消或验收后仍可移除未执行的自定义挂载，释放草稿，但不能重新启用结束的 Worker。

动作已经开始时不能撤销。明确失败不会自动重试；执行结果未知（例如创建途中 daemon 重启）也不会重放。先核查已有 Worker、worktree 和执行记录；需要恢复时移除旧授权，再显式新建。未知状态仅停用不会释放草稿。移除挂载不删除已经产生的 Worker、代码或消息。

多个合并排队时，runtime 在每次真正释放父执行位后给等待的创建 Hook 一个机会，再推进下一项；正在修复分歧或未知落地仍占位时不会强行解锁。

模型摘要可读，但完整 Prompt、env、运行资源与私有 Hook JSON 不出现在 Worker/API 结果中。CLI / RPC 见 [Hooks 接口](reference/rpc/hooks.md)；维护契约见 [Hooks 工程边界](engineering/hooks.md)。
