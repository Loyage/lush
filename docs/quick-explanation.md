# 旧快捷解释历史

新的解释、整理和速记入口已升级为[快速对话](quick-chat.md)：全局统一历史、独立对话页、C 编号和多 Prompt。旧 `#quick-explain` 设置书签引导快速对话设置，共用原设备模型来源配置。

已有项目解释和追问仍保存在原项目，项目「旧解释历史」入口可回看选区、结果、来源／Prompt 快照和历史追问。不自动搬迁为全局 C 对话，也不改写已有编号或正文。原项目接口保持兼容，边界见[旧工程契约](engineering/quick-explanation.md)。

旧记录仍可按其原有能力追问或确认后永久删除。旧式没有来源快照的记录不能继续；在途解释／追问不能删除，删除会连同其追问一起移除，不取消调用。来源变更不改写历史，不把模型输出当作执行事实。
