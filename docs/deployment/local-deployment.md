# macOS / Linux 本机部署

本文面向在 macOS 或 Linux 上使用 Lush 的用户，解释运行位置、界面选择和数据边界。具体环境检查与配置交给[本机 Agent 部署指导](agent-guide.md)；Windows 本机后台另走[WSL2 方案](windows-wsl2.md)。

## 为什么后台和项目放在同一台机器

Lush 的工作不只是请求模型，还要读取项目、创建 Git worktree、执行工具、验证并交付提交。因此项目、Git、编码 Agent 和项目 daemon 需要在同一个后台环境中工作。

本机方案复用你现有的开发环境，不要求上传代码到另一台服务器，也不需要安装整机调度服务。与模型服务的联网及模型费用仍取决于你选择的 Agent 和服务商；“本机部署”不代表所有模型都离线运行。

分层保持不变：浏览器 / Electron 负责交互，Host 负责项目入口与转发，每项目一个 lushd 持有该项目的 `.lush/`、Worker 和 Git 状态。Host 不汇总或迁移各项目的事实，详见[三层边界](../engineering/host-boundary.md)。

## 选浏览器还是桌面

| 方式 | 为什么选它 | 需要准备 |
|---|---|---|
| 浏览器 + Host | 环境较简单，多标签访问项目，适合首先打通部署 | 本机 Bun、Git、已认证的 Pi/Codex 与 Lush 代码 |
| Electron 本地窗口 | 希望有独立窗口和本地目录选择 | 上述后台环境，加源码依赖中的 Electron |
| Electron 远程窗口 | 项目和开发工具在另一台机器 | 按[远程桌面说明](remote-desktop.md)连接，不在客户端复制项目 |

两种本机界面使用同一套业务 UI/API，不是两套 Worker 系统。源码桌面入口通过 Bun 启动；不能把 Windows 安装包“无需 Bun”的条件套用到 macOS/Linux 源码入口。

## 多项目与单项目有什么区别

无显式项目的 Host 是多项目入口：首次选目录，后续可以分别打开多个项目。已登记目录和上次项目只是界面记录；打开项目时才按需启动或连接它的 daemon。

显式单项目 Host 绑定一个项目，适合部署时减少选择与排错变量；它不代为启动 daemon，所以 Agent 必须先启动该项目 daemon。部署命令统一放在[Agent 指导](agent-guide.md#2-启动)。

每个项目必须是有初始提交的 Git 工作区根目录。页面里选目录不等于授权丢弃未提交工作；环境配置也不应替你提交或整理原有代码。

## 数据与凭证为什么这样保存

- 项目运行状态留在项目 `.lush/`，不能跨目录直接复用或删除。
- Host 的项目列表是用户级入口记录，不是另一份项目数据库。
- 编码 Agent 使用运行后台的用户环境；不要把模型密钥提交进仓库。
- `.lush-agent/` 可用于可提交的补充指令，私有设置留在项目 `.lush/`；细节见[Agent 环境与权限](../reference/agent-environment.md)。

已有项目要搬目录、已有后台要换版本时，先检查运行中的工作和项目绑定，不能靠强制删除状态目录“修复”。

## 默认只在本机使用的原因

未配置公网认证的 Host 只监听回环地址，适合可信的本机用户。Agent 拥有当前用户的操作系统权限，Lush 不是不可信代码的安全沙箱。

需要从另一设备访问时，应明确选择[远程 Host 方案](remote-host.md)：SSH 隧道或带认证的 HTTPS。不要仅把端口暴露到局域网，也不要用关闭防火墙作为快捷配置。

## 运行和升级时需要知道什么

关闭浏览器不停止 daemon；桌面退出会停止自己创建的临时 Host，但不停止项目 daemon。删掉列表中的项目记录也不是停止或删除项目。

Host 与 daemon 是两个独立进程：更新源码或环境后，运行中的旧进程不会自动换版本，需分别检查和重启。重启应先确认没有需要保留的活动工作；系统重启或故障后的恢复不会自动重放结果未知的调用。

默认按需运行，不设置自启或服务托管。需要持续在线时再讨论机器休眠、启动托管和备份，不将“后台进程”误当作已经配置好的系统服务。

## 部署完成应拿到什么

部署 Agent 应交付项目与 Lush 路径、工具版本、页面地址、Agent 配置（不含密钥）、Host/daemon 代码身份、实际验证结果、日志位置和下次启停命令。

页面能打开只证明界面入口可用；真实 Agent 调用需另经你同意，并说明模型费用和文件改动范围。自动测试、真实桌面操作和真实模型调用应分别报告，不混为已验证。
