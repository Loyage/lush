# 远程 Host：用户自行配置访问

远程开发时，用户在服务器准备并运行 Lush，用浏览器访问该服务器的 Host。项目目录、Git、Agent、模型凭证和 lushd 都在服务器；浏览器不复制 `.lush/`。后台准备见[本机部署](local-deployment.md)，Host 配置见[Agent 指导](remote-host-agent.md)。

## 网络由用户管理

Lush 不提供 SSH 连接、远端安装、隧道管理或跨 Host 代理。用户自行维护服务器、SSH、端口转发、防火墙、IP/端口、域名、证书与反向代理。

| 访问方式 | 取舍 |
|---|---|
| 自建 SSH 回环隧道 | Host 可保持回环监听；需自己保持隧道运行和核对 SSH 主机身份 |
| IP 加端口，HTTP | Host 允许，但密码、会话和项目内容可能被窃取或篡改；不建议在不可信网络使用 |
| 域名 + HTTPS（推荐） | 用户配置证书、反向代理与网络隔离；加密传输仍需 Host 登录认证 |

本机、SSH 隧道与公网访问均必须登录；缺少对应作用域的 `web.json` 时 Host 拒绝启动。新 `version:2` 配置默认仅监听回环，显式 `listen:"public"` 才监听所有 IPv4 接口；旧 `version:1` 仍保留全接口监听并警告，不自动改变部署。单项目配置位于 `<project>/.lush/web.json`；全局工作台使用用户配置目录的 `web.json`，公网必须另有 `projects` 绝对路径白名单，回环可省略或选择限制。字段、权限与模板见[配置指导](remote-host-agent.md#3-配置认证与项目范围)。

HTTP 风险警告不是禁止访问，也不会取消认证、Host/Origin 校验或项目白名单。SSH 隧道保护传输，但本地转发端口仍可被本机其它进程访问，不能替代 Host 登录，也不构成多用户隔离。不要绕过 TLS 或 SSH 主机校验。

## 手机 PWA 与后台提醒

使用固定域名和 HTTPS 打开 Host，通过浏览器菜单安装／添加到主屏幕。iPhone／iPad 需要 iOS／iPadOS 16.4 或更高版本，并从主屏幕 Web App 中启用通知；普通浏览器标签页不能替代。Android 需要支持 Push API 的浏览器，实际送达还取决于系统省电策略及浏览器推送服务的网络可达性。

在「设置 → 界面」开启系统通知总开关，再为当前手机启用后台推送；授权只由用户点击发起，不替其它浏览器授权。可以发送测试通知，关闭页面、锁屏后检查是否出现，再点击核对来源项目。测试发送成功只代表推送服务接受请求，不证明手机已经收到。停用当前浏览器的后台推送与关闭设备系统通知总开关是不同操作，前者撤销本客户端订阅，后者影响所有客户端的正常提醒。首次启用不补发历史，关闭总开关期间的事项也不在重新开启时补发。

后台提醒由持续运行的 Host 从有权访问的来源项目派生，只读同步不启动停止的 daemon。通知默认使用泛化摘要，不把代码或问卷正文送到锁屏；点击只导航，不答复、标已读、合并或验收。Web Push 仍经过浏览器厂商的推送设施，不是完全自托管的直连长连接；服务器及手机必须能连接相应服务。权限撤销、订阅过期、网络限制、勿扰模式或系统强制停止均可能影响送达，重新打开后以来源项目记录为准。

PWA 不缓存受保护的业务页面、API 或项目内容，离线不能继续操作。界面由 Host 提供：服务器安全更新并重启 Host 后，在手机重新加载即可获取新渲染资源，不需要随每次界面发版更新安装包；不会强制刷新正在编辑的页面。修改域名／站点身份或清理浏览器数据后，需要重新检查安装与订阅。整台服务器宕机的告警需要独立外部监测，不能由同一台已宕机的 Host 保证。

## 生命周期与信任

关闭浏览器或用户自建隧道不停止远端 daemon。重新连接后先读状态，不自动重发未知结果的写操作。Host 和各项目 daemon 分别检查代码身份、分别更新；停止入口不等于停止项目。

Lush 是可信用户开发工具，不是不可信多租户沙箱。Agent 拥有后台用户权限；登录与目录白名单不是操作系统隔离。控制访问人员与网络范围，审阅交付，不复制或删除项目状态来排错。

## 验收

分别证明后台与项目可用、代码身份匹配、实际客户端可达、登录与项目白名单有效、监听及网络暴露符合预期。报告 HTTP 明文风险或 HTTPS/SSH 实际保护，不把文件配置完成当作端到端验证。真实模型调用另获同意。
