创建 worktree-service：调用 service_spawn，参数 template="worktree-service"、name=<worktree 短名，必填>、goal=<在这个 worktree 上要长期做的事，可选>、variables={"path": "<worktree 的绝对路径>"}；命令行等价于 `lush service spawn <你的 SID> worktree-service --name <短名> [--goal '<目标>'] --vars '{"path":"<绝对路径>"}'`。path 是本模板唯一声明的变量，必填且不可变：必须是「已经存在」的绝对目录——先 `git -C <仓库> worktree add <目录> -b <分支>` 把 worktree 建出来，再创建本节点；不是绝对路径、不存在或不是目录时创建直接失败（-32602）。它绑定的就是这个 worktree：path 同时是该节点上所有 task 的工作目录。singleton=false，但约定是「一个 worktree 一个节点」：创建前先看 children，path 相同的就复用。它是叶子节点（child_templates 为空）：创建后用 `lush task spawn <它的 SID> --goal '<要改什么>'` 派活，再结束本轮——它结算时你会被唤醒并拿到结果。
