创建 project：必须提供模板变量 path（不可变）：service_construct {template: "project", name: <项目短名，必填>, goal: <项目目标，可选>, variables: {"path": "<绝对路径>"}}，命令行等价于 `lush service construct <parent> project --name <短名> [--goal '<目标>'] --vars '{"path":"<绝对路径>"}'`。path 必须是已存在的绝对目录，它同时是该节点上所有 task 的工作目录（cwd）；缺失 / 相对 / 不存在都会创建失败。另有可变变量 branch（默认 main），创建时可不传，之后由这个节点自己用 `lush service update-vars` 修改。singleton=false，同一个父服务下可以建多个项目。创建后它不会自动干活：要让它干活，用 `lush task construct <它的 SID> --goal '<目标>'` 派一个 task 给它，然后结束本轮——它结算时你会被唤醒并拿到结果。
